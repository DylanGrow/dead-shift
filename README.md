# DEAD SHIFT - Top-Down Zombie Survival Roguelite

**Dead Shift** is an original, production-quality top-down zombie survival roguelite built purely using client-side Web technologies (HTML5, CSS3, ES2023 JavaScript, Canvas 2D API, Web Audio API).

## Features
- **40+ Unique Weapons**: Pistols, Shotguns, Snipers, Flamethrowers, Rocket Launchers, Katanas, Laser Cannons, Drone Swarms, Orbital Strikes, and Mythic Weapons.
- **30+ Enemy Types & 5 Multi-Phase Bosses**: Walkers, Acid Spitters, Mutants, Screamers, Flying Spectres, and huge multi-stage Boss fights.
- **150+ Powerups & Augmentations**: Elemental Damage (Burn, Freeze, Poison, Lightning, Bleed), Turrets, Companions, Crit Builds, Glass Cannon, and Magnet Pulls.
- **15 Handcrafted Maps & Dynamic Weather**: Downtown, Hospital, Rooftops, Forest, Factory, Laboratory, Acid Storms, Blood Moons, and Fog.
- **Zero Third-Party Dependencies**: Pure client-side code, procedural Web Audio synthesizer, and vector-rendered Canvas graphics.
- **Multi-Device Support**: WASD + Mouse, Touch Joysticks, Gamepad, Auto-Aim assist, Keyboard Remapping, and High-Contrast Accessibility.
- **Progressive Web App**: Offline capable with Service Worker caching and local storage persistence.

## How to Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Select `main` branch root as the source and click **Save**.
4. Access your live game at `https://<username>.github.io/<repo-name>/`.
